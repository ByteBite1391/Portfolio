Identity

A developer who thinks in systems.

I work mostly on the server side: designing data models, building REST APIs with Django and Django REST Framework, wiring them to PostgreSQL, and shipping everything in containers. I also enjoy the front end enough to build interfaces — including the 3D world you are standing in right now.

Backend first

APIs, authentication, database design, serializers, permissions and the boring-but-critical parts that make a product stable.

Full-stack capable

Comfortable moving between Django templates, JavaScript, HTML and CSS to deliver a complete, working product.

Container-minded

Docker for reproducible environments, Git for history and collaboration, clear project structure over clever shortcuts.

Always learning

Continuously expanding the stack — this portfolio itself was built to experiment with Three.js and real-time 3D on the web.

“Write it so the next person — usually future me — can read it, run it and change it.”
